# Milestone 3: Internal AI Runtime Contracts

This milestone defines the reusable runtime contracts that all future implementation work must follow.

## Scope

- Runtime API specification
- Agent contract specification
- Evidence graph specification
- Event system specification
- Deterministic tool framework
- Provider abstraction framework
- Runtime state machine
- Production repository layout
- Architecture decisions and diagrams

## Non-Goals

- React UI
- Express APIs
- Route handlers
- Business logic for individual agents
- Provider-specific integration code
