# Milestone 4: Runtime Kernel

This milestone defines the kernel that hosts every future runtime component.

## Scope

- RuntimeKernel
- RunManager
- RuntimeContext
- Component Registry
- Policy Framework
- Capability Registry
- Kernel Lifecycle
- Dependency Injection Design
- Sequence diagrams
- Type-only contract updates

## Non-Goals

- Express APIs
- React UI
- Agents, tools, or business logic
- Provider-specific implementation code
